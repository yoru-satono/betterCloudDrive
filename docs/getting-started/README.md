# 入门指南

本目录面向第一次接触 BetterCloudDrive 的使用者和开发者，目标是用最短路径完成环境准备、首次启动和基本健康验证。

## 推荐阅读顺序

1. [Docker Compose 快速启动](QUICKSTART.md)：复制配置、设置密钥、启动、健康检查和首次注册。
2. [开发环境准备](DEVELOPMENT_SETUP.md)：按后端、Web、Qt 或 KMP 移动端组合本地环境。
3. [常见排障](TROUBLESHOOTING.md)：容器、端口、地址、工具链和专项服务问题。

根目录 [README](../../README.md) 只保留项目概览和最短启动入口；完整变量表仍以[配置参考](../reference/CONFIGURATION.md)为准，生产操作以[运维手册](../operations/README.md)为准。

## 范围边界

本目录不维护全量环境变量表、生产运维流程或内部架构说明；这些内容分别属于 `reference`、`operations` 和 `architecture`。测试命令和最低验证位于[开发测试策略](../development/TESTING.md)。
