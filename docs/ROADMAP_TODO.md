# BetterCloudDrive 后续任务清单

本文档把当前团队模块、OnlyOffice、Web/Tauri、Android、测试和运维待办拆成可单次执行的小任务。后续可以直接按任务编号下达，例如：`执行 BE-01`、`实现 AND-03`、`跑 TEST-02`。

## 使用规则

- 每个任务都应该能在一次开发会话内完成，除非验收条件明确依赖外部服务、模拟器或完整 E2E 环境。
- 执行任务前先确认当前工作树，避免覆盖未提交改动。
- 涉及接口改动时同步更新后端、Web/Tauri、Android、测试和 `docs/API.md`。
- 涉及用户可见行为时至少补一层测试：后端单测或黑盒、前端单测或 E2E、Android 单测或 E2E。
