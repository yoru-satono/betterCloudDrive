## Web/Qt 共享产物与公共实现（2026-11-24）

当前只构建 `frontend/dist`，浏览器和 Qt 使用同一入口、认证 Store、HTTP client、身份版本、预览 Store、Office 脚本加载器和编辑器组件。原 `desktop/web` 及专用 Vite 别名已删除；`desktop/build.py` 调用与 Web 相同的 `pnpm run build`。Qt 在可信主页面 DocumentCreation 阶段注入不可变的公开平台/默认地址配置，QWebChannel 仍在隔离 world，子帧不获得配置或通道。浏览器不等待或加载原生传输。Qt 启动默认值不再进入构建，地址优先级见操作说明及配置参考。

两端统一采用退出即清身份、请求和原生命令的同步身份捕获、迟到响应拒绝、一次刷新与并发合并、预览资源回收、HTML/XML 纯文本和 Office 重试/销毁。Web 视频使用浏览器 `<video>`，Qt 使用原播放器；WebM 在后端标为 `application/octet-stream` 时按扩展名选择视频及 Blob MIME，不改后端映射，也不承诺浏览器支持所有格式。
