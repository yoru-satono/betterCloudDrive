# 阶段 6：个人文件管理

## 交付范围

本阶段在个人文件浏览器上增加当前目录新建文件夹、单项重命名、移动、递归复制、单项删除，以及当前目录多选和批量移入回收站。多选只用于删除；重命名、移动和复制仍一次处理一个项目。当前目录和多文件上传、回收站界面、搜索、预览及团队文件管理不属于本阶段。

Android 应用版本为 `versionCode=7`、`versionName=0.7.0-stage6`。Room schema、传输引擎、旧 Android 应用和 iOS 平台服务均未修改。

## 后端契约

- 创建和重命名先修剪名称，规范化后必须为 1～255 字符。
- 创建父目录和移动/复制目标必须属于当前用户、未删除且为文件夹。
- 文件与文件夹在同一父目录共用名称空间；冲突统一返回 `409001 / error.fileNameConflict`。
- 同名重命名和同父目录移动幂等成功，不更新时间。
- 文件夹不能移动或复制到自身及后代，错误键为 `error.invalidFileDestination`。
- 文件夹复制完整活动子树，复制名称使用 ` (copy)` 后缀；超长名称会先安全截断。
- 批量删除先去重并保持事务原子性。同一用户的个人文件变更通过用户行锁串行化，不需要数据库迁移。

## KMP 状态与界面

五类变更请求复用认证、单飞刷新、一次重放和语义错误处理。页面状态分别保存选择集合、当前单飞操作、可消费反馈和文件夹选择器，不把服务端错误键直接显示给用户。

长按文件行或网格卡片进入选择模式；选择模式中单击切换选中状态，列表/网格切换和加载更多保留选择。刷新、排序、切换目录或顶层页面会清空选择。每个项目都提供显式更多菜单，包含重命名、移动、复制和移入回收站。

目标文件夹选择器从个人根目录开始，每页按名称读取 100 条，并在遇到第一个普通文件后停止继续翻页。文件夹源会被隐藏，因此无法进入其子树。手机使用全高底部页，宽屏使用居中对话框；移动到当前父目录不能确认，复制到当前父目录允许。
