# 阶段 8：个人预览与搜索

## 交付范围

阶段 8 在个人文件浏览器中加入全局文件名搜索和只读预览。搜索使用现有 `/files/search` 接口，每页 50 项，输入停止 300 ms 后发起请求；快速输入会取消旧请求，分页结果按文件 ID 去重。搜索页属于“个人”导航分支，从目录进入搜索或预览后返回，原目录、排序、分页和滚动锚点不会丢失。

普通文件支持以下预览类型：

- Office 文档：请求个人 OnlyOffice 配置时固定携带 `mobile=true`，Android WebView 原样加载后端签名的移动只读配置。
- 图片：PNG、JPEG、GIF、SVG 等通过现有下载 ticket 交给 Coil 3.5.0 加载，支持缩放、拖动和双击复位。
- UTF-8 文本：使用认证下载接口读取 `bytes=0-524287`，识别 UTF-8 BOM，超过 512 KiB 时显示截断提示。
- 视频：通过现有下载 ticket 交给 Media3 1.11.0 流式播放，支持 Range 和拖动定位；离开前台会暂停，页面销毁会释放播放器。
- 其他类型：展示只读的不支持提示，并保留下载入口。

应用版本为 `versionCode=9`、`versionName=0.9.0-stage8`。本阶段没有新增后端接口、数据库迁移、Room schema 或传输协议，也没有修改旧 Android 应用。

## 安全边界

图片和视频沿用现有 24 小时下载 ticket，但 ticket URL 只保存在当前预览的内存状态中。它不会进入 Navigation 路由、Room、DataStore、磁盘缓存、日志、错误文本或无障碍描述；离开预览、退出登录和切换服务器时会立即丢弃。Coil 明确禁用 ticket URL 对应的磁盘缓存，Media3 不启用媒体缓存。

文本内容只在 Ktor 响应作用域内读取，最多保留 512 KiB；HTML 和 Markdown 都按原始文本展示，不执行脚本。所有预览请求沿用认证层的单飞刷新和最多一次重放。媒体 ticket 失效时自动重新申请一次，第二次失败后进入显式可重试错误状态。

## 状态与导航

- 空搜索词不访问网络；搜索状态分别表示初始提示、加载中、结果、空结果、首次失败和加载更多失败。
- 搜索结果可打开文件夹、打开文件所在目录、预览或下载。“打开所在位置”只导航到父目录，不为定位项目遍历整个大目录。
- 搜索查询、结果和当前预览状态在 Activity 重建期间由应用状态持有者保留；进程被强制停止后，恢复会话仍从个人根目录开始。
- 同时只允许一个活动预览。打开另一个文件或离开页面会取消上一请求，协程取消不会被包装为普通网络错误。
- 预览页隐藏产品底栏或侧边栏，系统返回键回到搜索结果、文件详情或原目录。

## 验收记录

阶段 8 已于 2026-08-25 完成自动化与 API 34 真实旅程验收：

- 搜索准备了不少于 105 个同前缀项目。服务端分页返回 111 个结果，页面连续加载三页也得到 111 个唯一项目，无缺失或重复；快速改词、文件夹打开、已缓存和未缓存目录的“打开所在位置”及两级返回栈恢复均通过。
- PNG 与 SVG 正常加载，缩放、拖动和双击复位可用；应用缓存中没有落盘的 ticket 媒体文件。
- 零字节文本显示空文本状态；带 UTF-8 BOM、超过 512 KiB 的文本显示截断提示，范围边界后的标记没有进入页面。
- 7.259 秒 MP4 可播放和拖动，后端记录 5 次 `206`。切到后台会暂停；开启“不保留活动”重建后恢复到约 3 秒但不自动播放，页面只有一个 Activity/播放器实例。
- DOCX 显示唯一测试标记和“OnlyOffice 文档已就绪”，持续观察超过 20 秒未出现商业许可警告、编辑入口或桌面编辑切换。
- 退出各预览并登出后，应用日志与私有文件中未发现 ticket URL、Bearer Token、响应正文或 SAF URI。
- `mobile-unit`、API 28/34 `mobile-android`、141 项 `blackbox` 和 7 项 `observability` 全部通过；Debug、Release/R8、国际化门禁和 iOS 公共代码元数据编译通过，完整 14 服务 Docker 栈健康。
