# 阶段 12：个人回收站与文件版本

## 交付范围

阶段 12 为 KMP 个人空间补齐回收站和历史版本能力。应用版本为 `versionCode=13`、`versionName=0.13.0-stage12`。

- 个人空间“整理”菜单提供回收站入口，支持 300 ms 防抖搜索、每页 50 项、刷新、尾部重试、单项恢复、永久删除和清空。
- 回收站采用删除根模型：文件夹作为一个根进入列表，后代从直接访问、搜索、收藏、标签、分享、预览和下载中隐藏。
- 普通个人文件可从目录、搜索、收藏、标签列表和详情进入版本历史，支持恢复、删除与通过系统目标选择器下载。
- 历史版本下载进入现有可恢复传输队列，沿用 `.part`、Range、MD5、暂停、恢复、UIDT/WorkManager 和终态清理。
- 团队回收站、团队版本、批量恢复、批量永久删除、历史版本预览和新增版本产生入口不属于本阶段。

## 后端与数据边界

回收站列表只返回当前用户个人空间的删除根，固定按删除时间和 ID 倒序，响应不包含存储路径。恢复优先使用仍有效的原父目录，否则回到根目录；同名冲突保持在回收站，恢复前按整棵子树重新检查配额。永久删除、手动清空和定时过期清理复用同一递归对象与元数据删除逻辑。

版本接口只接受当前用户未删除的个人普通文件。安全 DTO 不返回存储路径或用户 ID；恢复会先保存当前内容并检查配额，删除会更新容量与版本计数，最后一条可保留历史记录由 `409003 / error.cannotDeleteOnlyVersion` 保护。版本下载支持标准 `200/206/416` Range 响应。

移动端 Room 从 v1 升级到 v2，为传输任务增加可空 `remoteVersionNumber`。迁移保留现有任务；空值继续下载当前文件，非空值选择历史版本端点。`PersonalRecycleBinStore` 与 `PersonalVersionsStore` 各自拥有状态、作业、反馈和重置边界，内容变化通过窄回调统一失效相关个人缓存。

## 验收状态

阶段 12 已于 2026-09-01 完成。后端单元、Testcontainers、Web/Tauri、黑盒契约、KMP 主机测试、国际化门禁、Debug、Release/R8、iOS 元数据以及 Android 9/API 28 与 Android 14/API 34 设备测试均成功。最终黑盒运行 `bcd_20260901_203730_25524` 通过 148 项测试；完整可观测性运行 `bcd_20260901_203943_6356` 通过 Prometheus 规则测试和 7 项专项测试。黑盒契约额外验证了删除树只暴露根、后代入口隐藏、安全 DTO、恢复，以及历史版本 `200/206/416` 下载、恢复计数和稳定最后版本冲突。

API 34 的 64 MiB 历史版本 SAF 下载真实旅程也已通过：源文件大小为 67,108,864 字节，MD5 为 `c28dcdd0b4269dd842c6d8d97364f91b`；在 `.part` 已写入后两次强制停止应用，重新打开后分别从 `1,261,535` 和 `20,060,313` 字节发送 Range 请求并获得 `206`。任务继续复用同一 Room 记录和 UIDT 调度，最终目标文件大小及 MD5 与源文件一致，任务状态为成功，临时 `.part` 已删除。由此“个人功能对等”里程碑达成。
