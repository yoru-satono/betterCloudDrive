# 阶段 10：个人收藏与标签

## 交付范围

阶段 10 为 KMP 个人空间增加收藏与标签整理能力。应用版本为 `versionCode=11`、`versionName=0.11.0-stage10`。

- 个人空间顶栏“整理”菜单提供收藏和标签入口，不增加第五个顶层导航项。
- 收藏页只展示当前账号未删除的个人文件和文件夹，支持每页 50 项、300 ms 防抖搜索、刷新、滚动加载和取消收藏。
- 标签页支持名称搜索、创建、重命名、预设色板改色和删除；删除标签只清除关联，不删除文件。
- 标签文件支持分页、搜索、移除当前标签、打开所在位置、预览和下载。手机使用独立页面，宽屏使用标签列表与文件列表双栏。
- 单个个人文件或文件夹可打开标签管理器。客户端一次读取全部个人标签及当前关联，保存时调用原子替换接口；创建新标签后会留在管理器并自动选中。
- 收藏、标签与文件变更成功后会使相关内存缓存失效；失败时保留已有列表、选择和表单输入。退出登录或切换服务器会清空个人整理状态。

团队收藏、团队标签、批量收藏、批量标签、收藏排序、标签拖拽、分享、回收站和版本管理不属于本阶段。

## 后端契约

个人收藏列表固定排除团队项目，并按收藏时间和文件 ID 稳定倒序。个人标签名称去除首尾空白且限制为 1～64 个字符，颜色使用 `#RRGGBB`；同名冲突统一返回 `409002 / error.tagNameConflict`。标签列表返回活动个人项目的 `fileCount`。

新增 `GET /api/v1/files/{fileId}/tags` 与 `PUT /api/v1/files/{fileId}/tags`。替换请求会去重标签 ID，在一个事务内验证文件和全部标签均属于当前账号个人空间，再精确替换关联；空集合清空全部关联，相同集合幂等成功。旧的逐标签关联接口继续保留给已有客户端。

Web/Tauri 的文件标签管理器已经切换到一次读取和一次原子保存，避免标签或标签文件超过 100 项时的误判及部分保存。

## 验收结果

自动化验证覆盖后端名称、颜色、冲突、归属、数量和原子替换，Web 端点契约，KMP 请求、分页、缓存、状态和导航，以及 Android 手机/宽屏 Compose 交互。设备矩阵继续使用 Android 9/API 28 与 Android 14/API 34。

阶段 10 已于 2026-08-28 完成验收：

- KMP 主机测试、国际化门禁、Debug、Release/R8 与 iOS 公共代码元数据编译通过。
- Android 9/API 28 与 Android 14/API 34 设备测试通过，覆盖个人“整理”导航、手机页面、宽屏标签双栏、标签分配界面及既有平台能力回归。
- 完整默认 Docker 栈重新构建并保持健康，Web 165 个单元测试、30 条浏览器 E2E、Tauri 14 个 Rust 单元测试和 3 个桌面 E2E spec 通过。
- 后端单元测试、Testcontainers 集成、143 条黑盒测试及 7 条可观测性验收通过。SeaweedFS 集成测试镜像固定为开发栈已验证的 `4.40`，避免浮动 `latest` 引入不可重复结果。
- 真实 API 旅程创建 105 个个人文件夹与一个团队文件夹，验证收藏和标签文件各连续加载三页且无缺失、无重复，个人收藏不混入团队项目；标签名称修剪、原子分配、去重、替换、清空和删除标签后文件保留均通过。连续写入未触发 HTTP 429。
- 真实旅程发现并修复了“已有标签关联参与原子替换时，删除尚未刷新便插入导致唯一约束冲突”的问题。修复后旧关联会先落库删除，再写入最终集合。

验收账号、团队、文件与关联数据已通过限定运行标记清理；完整 Docker 开发栈继续运行，两个 Android 模拟器均已关闭。
