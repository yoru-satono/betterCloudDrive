# 阶段 9：账号生命周期与个人设置

## 交付范围

阶段 9 将注册、密码找回和登录后的个人设置迁移到 KMP 应用。应用版本为 `versionCode=10`、`versionName=0.10.0-stage9`。

- 登录页之外新增注册验证码、注册、忘记密码和重置密码流程。注册验证码保留 60 秒重发倒计时，注册成功返回登录页并预填用户名；密码找回对账号是否存在使用统一反馈。
- “我的”只读展示用户名、邮箱、验证状态、角色、注册时间和存储用量，并允许独立刷新。资料刷新失败保留已有内容。
- 应用内语言支持 `en-US`、`zh-CN` 和 `zh-SG`。未登录选择立即应用并保存；登录后以账号精确地区为准，历史 `zh-Hans` 账号兼容映射为 `zh-CN`。
- 主题支持跟随系统、浅色和深色，只保存在当前设备，登出和切换服务器不会清除。
- 服务器仍采用单地址模型。有效新地址必须确认，确认后尽力登出旧服务器，并清理后台调度、Room 传输、临时文件、SAF 持久权限和令牌，再保存新地址并返回登录页。

本阶段不提供资料编辑、邮箱更换、头像、登录后修改密码、账号注销、WebDAV 设置、通知偏好或多服务器列表。iOS 仍只保持公共代码可编译。

## 地区兼容

后端账号偏好接受 `en-US`、`zh-Hans`、`zh-CN` 和 `zh-SG`。注册邮件根据请求的精确地区选择语言，其中 CN、SG 当前复用相同的简体中文模板。Web/Tauri、旧 Android 和 Grafana 收到 CN、SG 时映射到既有 `zh-Hans` 资源，但账号记录保留精确地区。

KMP 的系统资源回退边界保持不变：无地区 `zh`、系统无地区 `zh-Hans`、繁体中文和其他未支持语言回退默认英语。只有登录恢复历史账号偏好时，`zh-Hans` 才兼容映射到中国大陆简体中文。

## 安全与状态边界

- 注册、验证码和密码找回请求不携带已有会话，也不进入自动刷新链路。
- 表单提交、资料刷新、语言保存和服务器切换使用相互独立的忙碌与错误状态，取消不会被包装为普通网络错误。
- 登录后的语言修改先更新后端，成功后再应用 Android per-app locale；失败保持原语言。通知、无障碍文本、文件选择器和 OnlyOffice 回调读取同一有效 locale。
- 切换服务器前无效或未变化的地址不会清理任何状态。切换成功后导航栈回到登录页，语言和主题仍保留。

## 验收记录

阶段 9 已于 2026-08-27 完成验收。

- Android 9/API 28 的 26 项设备测试和 Android 14/API 34 的 27 项设备测试通过，覆盖真实资源环境、应用重建、Keystore、Room、WorkManager/UIDT、通知与 SAF 回归。API 34 测试增加了运行前语言复位，避免设备保留的应用语言污染英文断言。
- API 34 真实旅程从 `zh-SG` 注册开始：Mailpit 收到简体中文验证码邮件，后端保存精确 `zh-SG`；登录、强制停止和恢复后仍显示 SG 简体。随后依次切换英语、CN 简体和 SG 简体，后端精确偏好、移动端界面与通知保持一致，Web/Tauri 继续映射到 `zh-Hans`。
- 系统、浅色和深色主题均即时生效；最终选择的系统主题在强制停止、登出和服务器切换后保留。密码找回验证了统一公开反馈、中文邮件、旧密码失效和新密码登录成功。
- 在存在暂停的大文件上传时切换到同一后端的另一个可访问地址，应用清除了令牌、Room 任务、系统调度、临时文件和持久化 URI 权限，同时保留语言与主题。系统在 Activity 存活期间可能短暂显示文件选择器授予的非持久化授权，但该授权不能跨进程恢复。
- 完整 14 服务 Docker 栈通过带构建启动和健康检查。后端单元与集成测试、Web 164 项单元测试和 30 项 E2E、Tauri 14 项 Rust 测试与 3 组桌面 E2E、141 项黑盒测试、7 项可观测性验收均通过。
- KMP Host 测试、国际化门禁、Debug、Release/R8 和 iOS 公共代码元数据编译通过。发布编译同时补齐了 Activity 生命周期收集所需的正式依赖。
- Web E2E 与 Tauri/黑盒共用测试专用限额，测试结束自动恢复生产默认值；后端容器重建后同步刷新前端网关，避免保留失效的容器地址。人工测试账号、上传会话、存储对象、邮件和自动化测试数据已按受限范围清理，完整 Docker 开发栈保留运行。
