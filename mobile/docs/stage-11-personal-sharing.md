# 阶段 11：个人分享

## 交付范围

阶段 11 为 KMP 个人空间补齐分享创建、管理、编辑和撤销能力。应用版本为 `versionCode=12`、`versionName=0.12.0-stage11`。

- 个人空间“整理”菜单提供分享管理入口；个人目录、搜索、收藏、标签文件列表和文件详情可为单个个人文件或文件夹创建分享。
- 创建分享支持可选密码、正整数访问上限、永不过期、1 天、7 天、30 天和设备时区下的自定义日期时间。
- 分享列表每页 50 项，支持 300 ms 搜索防抖、密码状态和有效期筛选、刷新与尾部重试。手机使用独立详情页，宽屏使用列表与详情双栏。
- 分享详情支持按需查看和隐藏密码、复制链接或密码、明确设置/移除密码、设置/清空过期时间和访问上限，以及幂等取消分享。
- 明文密码只保存在当前详情内存状态；离开详情、退出登录或切换服务器时清除，不进入路由、Room、DataStore 或日志。复制动作只在用户主动操作后写入系统剪贴板。

公开分享访问、保存他人分享、公开下载、深链、邮件通知、批量分享和团队分享不属于本阶段，继续由现有 Web 页面或后续阶段承担。

## 后端与兼容契约

个人和团队分享响应增加 canonical `shareUrl`、`expireAtEpochMs` 及可空的根项目名称、类型和大小。链接由后端根据 `APP_PUBLIC_URL` 生成，KMP 不猜测 Web 地址；旧 Web/Tauri 在新字段缺失时仍回退原有本地构造方式。

分享列表固定按创建时间和 ID 倒序，列表文件元数据批量读取。个人列表排除团队分享、已取消分享；密码去除首尾空白后限制为 4～16 个字符，访问上限必须为正整数。更新接口继续通过 `clearPassword`、`clearExpireAt`、`clearMaxVisits` 表达明确清空，取消操作幂等且成功后公开链接立即失效。

## 验收状态

阶段 11 已于 2026-08-28 完成验收：

- 后端单元测试与 Testcontainers 集成测试通过；Web 的单元测试和 30 条 Core E2E、Tauri 的 14 个 Rust 单元测试和 3 个桌面 E2E spec 均通过。
- 后端黑盒测试共 145 项通过。真实 API 旅程创建了 105 个个人分享，验证三页稳定分页、搜索与筛选、文件和文件夹分享、密码读取与更新、限制显式清空、个人/团队隔离、公开访问与下载计数、访问上限、幂等取消及取消后立即失效。
- Android 9/API 28 与 Android 14/API 34 设备测试通过；API 34 上最新 Debug 应用可正常启动，未出现崩溃。KMP 主机测试、国际化门禁、Debug、Release/R8 和 iOS 公共代码元数据编译均通过。
- 完整默认 Docker 栈保持运行，可观测性 7 项验收通过；分享密码、Bearer Token 和未脱敏访问凭证未进入验收输出。

本阶段没有扩展公开分享访问、保存他人分享、公开下载、深链、邮件通知、批量分享或团队分享的产品范围。
