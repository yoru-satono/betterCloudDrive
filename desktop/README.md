# Qt 桌面客户端

当前目标为 Windows 11 x64 开发运行版本。复用 `frontend/src/` 的 Vue 页面，通过本目录的独立 Vite 配置、运行时、会话适配和 QWebChannel 连接 Python。后端和 KMP 移动端不改；共享前端仅调整标题栏保存函数，等待桌面地址保存完成并处理失败，原 Web 请求和 Store 实现保持原样。

## 安装与启动

需要 pnpm 和 uv。Python 3.12.13、PySide6 6.12.0、HTTPX 0.28.1 由 `uv.lock` 固定，uv 自动准备隔离环境，无需系统 Python 或额外安装 Qt/FFmpeg。

在仓库根目录执行：

```powershell
cd frontend
pnpm install --frozen-lockfile
cd ../desktop
uv sync --locked
uv run --locked python build.py
uv run --locked python app.py
```

前端资源生成在 `desktop/web-dist/`。默认应用来源为 `http://127.0.0.1:5184`，默认后端为 `http://127.0.0.1:8080/api/v1`。登录前可通过标题栏设置 API 和 Web 分享地址；更换 API 会清除本次身份并暂停原生任务，随后重新登录。

地址保存等待原生 `connection:set` 确认后才写入网页配置并关闭设置框。失败时保留输入、显示错误；重新保存可恢复连接，不恢复旧服务器令牌。连接尚未确认时拒绝身份请求。Qt 构建使用独立的请求和身份适配，版本检查同时覆盖网页登录、刷新、原生同步及退出，迟到响应不能恢复已退出的身份。

`BCD_DESKTOP_API_BASE`、`BCD_DESKTOP_WEB_BASE` 可在构建时指定默认地址。启动参数 `--api-base` 指定初始原生 API；网页保存的连接设置会在启动时同步原生层。API 限定 HTTP(S)、无嵌入凭据、无查询和片段，路径以 `/api/v1` 结尾。

默认独立 Profile 为 `%LOCALAPPDATA%/BetterCloudDriveQt`，也可指定 `--profile <空目录或本程序已标记的目录>`。同一 Profile 使用文件锁防止多个实例同时运行。不读取 Tauri 或实验原型的登录态、设置和任务。

页面资源缺失、端口占用、Profile 不属于本程序或已被其他实例锁定时，显示明确的启动错误对话框；可分别重新构建、改用 `--port` 或指定独立 `--profile`。初始化中途失败也释放已创建的服务器及 Profile 锁。页面重载、渲染进程终止、窗口关闭和应用退出由原生层暂停任务并清除内存身份；重新认证后仍需手动恢复原任务。

## 桌面能力

- 无边框窗口、拖动、最大化/最小化、主题、原生文件与目录选择。
- 窗口及任务栏使用 `assets/app.ico` 的项目房形图标；Windows 使用独立应用标识，避免 uv 启动时与其他 Python 窗口合并。更换图标后下次启动生效。
- 标题栏拖动遵循系统拖动距离，普通点击不改变窗口位置；失焦或窗口状态变化会清除未完成的拖动状态。
- 个人及团队文件、批量及目录上传下载，保留空目录；目录树、子任务暂停/继续/取消。上传、下载分别按文件分配并发名额，默认各 3、范围 1～16；同一目录内的文件可以并行，各方向共享一个总速率限制。
- SQLite 保存设置与新任务。重启时未完成任务暂停，重新登录原账号和服务器后可手动继续；任务不会跨账号或服务器自动恢复。
- 原生上传发送逐项进度及批次完成事件，现有传输界面继续使用。网页拖放仍走现有 Web 上传路径。
- 图片、纯文本、PDF、OnlyOffice 使用网页预览。桌面适配丢弃关闭或身份变更前的迟到响应，释放 Blob URL，将 HTML/XML 作为纯文本展示；OnlyOffice 脚本加载失败可以重试，卸载后不再初始化编辑器。
- 视频复用一个独立 Qt Multimedia 窗口，支持播放暂停、松开进度条后跳转、音量、全屏、空格和 Escape，以及错误提示和重新授权重试。新视频先停止旧音频及来源，旧请求不能覆盖最新打开意图。网页预览与视频窗口独立，退出、切服及页面失效关闭二者。
- 播放器通过可撤销的回环网关访问现有后端，校验 Range、长度及文件版本，授权元数据用于 HEAD。按最多 4 MiB 分段完成后端读取，再发送给解码器，避免暂停或慢读长期占用后端异步响应。撤销会关闭本地及上游连接。后端 Token 不放入播放器 URL、命令行、状态数据库或日志。

暂停保留断点，取消下载清理该节点专属的临时分片。已有下载目标不会被覆盖；远端名称被清理后发生重名时，在同一个目录任务内自动追加序号。源码文件变化、损坏 Range、大小或 MD5 不符均拒绝发布最终文件。

原生代理支持关闭、手工 HTTP(S)/SOCKS5 代理和 Python 可识别的系统固定代理/代理环境变量；PAC/WPAD 不属于当前已验证能力，使用此类环境时请配置手工代理。代理用户名及密码仅在内存中保留，重启后重新输入；旧 Qt 设置中已有的代理凭据会在加载时移除。网页登录态位于独立 WebEngine Profile；不会导入旧客户端数据，也不会复制到任务数据库或验收报告。

## 传输恢复与设置

- 目录先创建再执行后代；父目录失败后，后代停止，独立兄弟节点可以继续。从失败父目录恢复会重新处理其未完成后代，已完成文件不重复执行。
- 排队、限速和重试等待可以暂停或取消。并发调整影响后续文件调度，降低限制不强杀正在执行的文件；限速调整及时生效。代理更改用于后续请求，已有响应流继续使用原连接。默认下载目录仅影响新任务，已有任务保留原目标。
- 对连接中断、超时及 HTTP 408/429/502/503/504，安全操作最多尝试 3 次（含首次），退避 1 秒、2 秒；429 遵循 `Retry-After`，单次最多等待 30 秒。上传分片的重发和下载重连流量计入总限速。401 最多刷新后重发一次，403、文件变化、磁盘和校验错误不作为网络故障重试。
- 元数据、上传状态、下载、相同会话的同一分片及幂等完成/取消可以重试。创建目录及初始化上传不自动重放；请求可能成功但结果丢失时标记“结果待确认”，普通继续被拒绝。请先核对服务端内容，再取消该任务并重新发起，避免重复对象。上传会话失效也不静默初始化新会话。
- 创建请求的未确认标记、返回的上传会话/文件身份及本地目录创建记录即时持久化，不使用进度通知的节流间隔。强制结束进程后，未完成任务保持暂停，同账号同服务器重新登录后才能手动继续。
- 空间不足、文件占用、目标已存在、目录联接/符号链接及错误 Range 均明确报错；最终文件通过长度/MD5 校验后原子发布，不覆盖已有文件。任务数据库写入失败时停止派发，检查应用数据目录后重启；设置保存失败保留此前生效的配置。
- 本地取消立即生效，远端上传会话异步清理；远端清理失败会单独提示。退出、切服前接收的命令和已排队的旧结果/事件不能恢复旧身份的任务队列。

## 验证

在仓库根目录运行：

```powershell
./scripts/verify-all.ps1 -Module qt
```

Bash 对应 `bash scripts/verify-all.sh --module qt`。此入口执行 Python 测试、真实 MP4/WebM 音视频解码及跳转、桌面专用 Vitest、桌面 Vue 构建和类型检查，不启动 Docker，不读写后端环境配置；`qt` 暂不并入原有 `all`。

Python 单元和媒体测试默认使用 `offscreen` 平台，不显示窗口、不抢鼠标键盘焦点。`validate.py` 默认会打开实际窗口；`--native-only` 只运行真实后端传输/会话检查，不打开窗口。

真实后端验收需要已运行的后端、存储、邮件服务；OnlyOffice 另外需要 DocumentServer。先确认 Linux 虚拟机关闭，再启动本机 Docker 服务；Linux 阶段反过来先停止 Docker。验收脚本自身不启动服务、不修改限流、不覆盖 env。

```powershell
cd desktop
uv run --locked python validate.py
uv run --locked python validate.py --office
uv run --locked python validate.py --native-only
uv run --locked python m1_check.py --offscreen
uv run --locked python m2_check.py
uv run --locked python m3_check.py --suite functional
uv run --locked python m3_check.py --suite access
uv run --locked python m3_check.py --suite playback
uv run --locked python m3_check.py --suite interaction
```

验收创建独立账号和受控文件/团队，验证真实断点传输、权限撤销、过期令牌、Vue 登录与原生任务、预览和退出。`--office` 增加真实编辑、保存回调、新版本内容和只读场景。报告只含非敏感结果，位于 `test-results/desktop/<run-id>/results.json`；测试账号保留审计，运行内文件、上传会话和团队按创建的 ID 清理，浏览器测试 Profile 删除。

`validate.py` 和 `m1_check.py` 默认使用独立端口 5194/CDP 9226，可通过 `--port`、`--debug-port` 修改，不自动关闭日常客户端。`--offscreen` 运行真实 Qt/Vue 和后端链路，不显示窗口；它不能代替 Windows 原生对话框、焦点、拖动与闪烁验收。`m1_check.py` 仅检查本阶段的登录、重载恢复、刷新、连接确认/失败恢复、服务器切换、退出和端口释放；服务器切换使用同一本地测试后端的 localhost/127.0.0.1 两种地址，要求 API 为其中一种回环地址。不要同时重建前端资源和运行真实页面验收。

`m2_check.py` 不显示窗口、不启动 Docker：使用独立账号和原生队列，真实强制结束并恢复 64 MiB 嵌套目录上传/下载，逐文件校验；验证账号/服务器隔离、个人/团队、权限撤销、HTTP/HTTPS/SOCKS5 代理认证、分片/完成响应丢失、结果未确认防重放、聚合限速，以及真实 Qt 设置页面保存和应用重启。凭据经匿名管道传给测试进程，不写命令行。HTTPS 代理夹具额外需要 OpenSSL（Windows 可自动使用 Git 自带版本）；临时证书只供该测试进程信任，不修改系统证书或代理设置。完成后清理测试 Profile、本地合成文件、状态和证书，仅保留不含敏感数据的报告；新建测试账号保留审计。该脚本使用回环后端的 localhost/127.0.0.1 两种地址验证服务器隔离。

开发诊断使用 `--debug-port` 显式启用回环 CDP；只有此模式接受窗口聚焦和非敏感状态查询。普通启动不开放 CDP，不提供任意文件路径上传或任意 HTTP 代理命令。

`uv run --locked python native_check.py` 为交互检查：选择终端打印的合成文件、拖动窗口，再选择打印的目录。`--m1` 额外检查取消/关闭；`--window-only` 只复验窗口手势和焦点。两者在打印 `CLICK_AND_FOCUS_NOW` 后等待本轮目录内的 `visual-accepted` 文件：验收者须先实际检查标题栏普通点击、轻微抖动、内容区点击、窗口失焦再切回后的首次点击及闪烁，原生标题栏按下计数须至少增加 3（普通点击、轻微抖动、切回后首次点击各一次），且窗口位置不变；然后通过本地终端创建该文件确认观察结果。它需要空闲桌面，按需运行，不与用户操作并行；不得预先创建确认文件。中断恢复仅用于本机开发测试，可显式运行 `uv run --locked python tests/recover.py --run <已有10位运行ID>`，只清理该运行新建账号的数据，不删除账号或数据卷。

只复验多文件与目录选择后的传输，可使用 `native_check.py --pickers-only`，不重复窗口手势检查。
